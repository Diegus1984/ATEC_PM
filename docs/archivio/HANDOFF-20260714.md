# Handoff Progetto ATEC PM — Linee Guida per Sviluppi Futuri

Questo documento descrive le ultime modifiche strutturali apportate all'applicazione ATEC PM, utili come riferimento (handoff) per sviluppi futuri da parte di altri agenti o programmatori.

---

## 1. Persistenza Visibilità Colonne

È stato implementato il salvataggio automatico dello stato di visibilità delle colonne per tutte le tabelle dell'applicazione web basate su **DataTableCard** o **DataTableCardFiltered**.

- **Funzionamento**: Quando l'utente seleziona o deseleziona le colonne tramite il menu a tendina, lo stato viene memorizzato in `localStorage`. All'accesso successivo, lo stato viene letto ed applicato in automatico.
- **Regola per futuri sviluppi**: 
  - Qualsiasi nuova tabella deve supportare la persistenza delle colonne.
  - Utilizzare o estendere i componenti generici [data-table-card.tsx](file:///c:/Users/diego/Desktop/ATEC_PM_CSharp_v5/ATEC_PM/atec-pm-web/src/components/shared/data-table-card.tsx) o [data-table-card-filtered.tsx](file:///c:/Users/diego/Desktop/ATEC_PM_CSharp_v5/ATEC_PM/atec-pm-web/src/components/shared/data-table-card-filtered.tsx).
  - La chiave di memorizzazione viene generata automaticamente a partire dal `title` della tabella (es. `table-visibility-preventivi`), ma può essere forzata passando la prop `visibilityStorageKey`.

## 2. Standardizzazione delle Stampe (Template Condiviso con Logo)

Per garantire un'identità visiva uniforme a tutte le stampe cartacee o PDF generate dalla Web App, è stato implementato un motore di rendering unificato per i documenti di stampa.

- **Helper Condiviso**: [print-template.ts](file:///c:/Users/diego/Desktop/ATEC_PM_CSharp_v5/ATEC_PM/atec-pm-web/src/lib/print-template.ts) espone la funzione `printHtml(options: PrintOptions)`.
- **Caratteristiche del Template**:
  - **Logo Ufficiale**: Include automaticamente il logo di **Automation Technology S.r.l.** (`/atec-logo.png`).
  - **Testata**: Titolo del documento, sottotitolo opzionale e griglia per i metadati variabili (es. numero elementi, data documento, periodo, pm).
  - **Margini e Layout**: Imposta i margini standard a `14mm` e include stili base coerenti (famiglia di font *Hanken Grotesk* o fallback *Segoe UI*, colori coordinati ATEC).
  - **Piè di Pagina**: Aggiunge automaticamente la data e l'ora di generazione del documento.
  - **Stampa automatica**: Gestisce l'apertura del popup e il ritardo di rendering necessario per avviare `window.print()` in modo pulito.

### 2.1 Esempio di Utilizzo dell'Helper in nuovi moduli
```typescript
import { printHtml } from "@/lib/print-template"

// Chiamata standard
printHtml({
  title: "Titolo del Documento",
  subtitle: "Sottotitolo del documento o descrizione",
  meta: [
    { label: "PM", value: "Diego" },
    { label: "Data", value: "14/07/2026" }
  ],
  contentHtml: "<table>...il tuo contenuto HTML...</table>",
  orientation: "landscape", // "portrait" | "landscape"
  paperSize: "A4",          // "A4" | "A3"
  customStyles: "th { background: #EAF1F9 }", // Stili specifici per la tabella
})
```

### 2.2 Stampe In-Place (es. Gantt del Resource Planner)
Se il modulo di stampa deve essere eseguito sulla pagina corrente per mantenere lo stato complesso dei componenti React (senza aprire popup), seguire il pattern implementato in `ResourcePlannerPage.tsx`:
1. Inserire il markup dell'intestazione di stampa all'interno della pagina:
   ```tsx
   <div className="gantt-print-header">
     <img className="gantt-print-logo" src="/atec-logo.png" alt="Automation Technology" />
     <div className="gantt-print-title">Pianificazione Risorse</div>
     <div className="gantt-print-subtitle">{periodLabel}</div>
   </div>
   ```
2. Gestire la visibilità tramite regole CSS in `@media print` (es. in `risorse-gantt.css`):
   - Nascondere `.gantt-print-header` di default a schermo (`display: none`).
   - Mostrarlo ed applicare lo stile ATEC standard sotto `@media print` per il corpo di stampa attivo.
